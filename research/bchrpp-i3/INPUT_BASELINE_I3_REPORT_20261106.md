# 输入基线 I3：工程验收与固定预算验证

状态：工程检查及沿用的验证保护门槛通过，I3锁定为MOSI/CH-SIMS下一阶段工作输入。

## 交付输入

- 文本：保持MMSA原文、标签、划分；英文DeBERTa-v3-large/中文RoBERTa-wwm-ext-large在线编码。两个发布元数据文件的实际SHA256与MMSA官方公布值一致。
- 音频：真实1秒窗口/0.5秒步长的局部CLAP512，与覆盖该锚点的最近真实全局4秒窗口CLAP512按通道连接，得到1024维。短片段使用完整真实片段。原有全局及新增局部向量全部保留。
- 视觉：每个真实采样帧只有一个时间步，将CLIP中心裁剪768维与保留完整视野的等比例letterbox768维连接为1536维。帧率不超过4fps，时间戳来自解码PTS。
- 文本、音频、视觉保持各自真实序列长度；没有均匀分配的伪词边界、假帧或超出媒体EOF的人工字窗。批处理填充位置显式标为无效。
- 模型适配仅扩展音频/视觉输入投影宽度。原路由、查询、损失、学习率与训练预算保持一致。为消除新增维度改变后续随机初值的混杂因素，复制原尺寸模型同一种子的随机核心参数，新增通道权重从零开始学习，恢复参考构造后的CPU RNG状态。三种子逐一检查了原核心参数一致性与初始投影等价性。

## 时间戳核查结论

[CMU官方SDK说明](https://github.com/CMU-MultiComp-Lab/CMU-MultimodalSDK/blob/main/README.md)明确说明旧MOSI词对齐已弃用，修正版只更新在原始词序列，未更新到GloVe/BERT。当前原始词文件入口不可用；下载到的旧GloVe CSD及由其生成的诊断锚点已通过DEPRECATED_TIMING_BLOCK.json明确禁止用于特征和训练。
诊断中，2199条CSD标签与当前标签数值对应；利用完整原录音进行波形定位，2195条短片段通过预设相关性门槛。GloVe字节匹配与序列检查得到的92.92%只是词身份对应覆盖率，不是边界准确率。诊断资料保留，未修改基准文本、标签、媒体或正式输入。
当前核心模型先对各模态独立编码、池化为证据节点，再进行跨模态融合，没有消费逐词时间戳的接口。正式输入采用媒体本身的实际时间轴和独立序列，与该结构匹配，不依赖缺失或已弃用的逐词时间戳。没有声称已获得全量准确的逐词/逐字对齐。中文自动对齐试验也未通过预设门槛，未用于正式特征。

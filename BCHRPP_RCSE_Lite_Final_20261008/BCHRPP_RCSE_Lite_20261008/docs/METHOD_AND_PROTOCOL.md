# RCSE-Lite：机制定义、公式与论文论证边界

## I. 解决的具体问题

旧模型先后估计来源置信度、反事实影响、动态竞争权重、图结构权重和两条独立预测头的仲裁权重。虽然各阶段可以单独解释，但在小规模多模态情感数据上容易出现冗余、计算链过长、辅助损失竞争，以及无法归因的精度变化。

RCSE-Lite 的核心假设是：**一个模态的差异信息只有在足够可靠时，才应该成为额外的协同价值；而这同一份证据授权应当贯穿直接预测与结构交互。** 这可以通过可信度估计、互补性门控、前后权重一致性和独立消融检验，而不必构造三路因果解耦和多重仲裁。

## II. 三阶段计算机制

符号：模态 m∈{T,A,V}；序列为 X_m∈R^{T_m×d_m}；隐藏维度 d，证据槽 Q；a_m 为可用掩码。序列 pad 在所有线性偏置与局部卷积前被掩蔽。

### 1) 局部编码与查询证据压缩

通过线性投影、共享的归一化/深度卷积和 Q 个可学习查询：

    H_m = LN(P_m(X_m)) + DWConv(LN(P_m(X_m)))
    alpha_{m,q,t} = masked_softmax_t( q_q^T H_{m,t} / sqrt(d) )
    z_{m,q} = Σ_t alpha_{m,q,t} H_{m,t}
    h_m = (1/Q) Σ_q z_{m,q}

实现中偏置、模态嵌入及 dropout 顺序以 `EvidenceEncoder` 为准。没有使用 Mamba 或预训练语言模型；输入保持用户原预提取特征。

### 2) 可靠性折扣互补性 + 共享路由

所有模态共用一个单模态预测探针 u(h_m)，另用一个共享质量头学习 r_m = sigmoid(g(h_m))。质量目标由探针预测误差决定，在学习可靠性时使用 stop-gradient：

    q_m (regression) = exp( -mean(| stopgrad(u(h_m)) - y |) )
    q_m (classification) = stopgrad(softmax(u(h_m))[y])

计算**有可靠性折扣**的跨模态差异：

    D(m,j) = (1 - cosine(h_m,h_j))/2
    c_m = r_m * [ Σ_{j≠m} a_j r_j D(m,j) / (Σ_{j≠m} a_j r_j + eps) ]
    γ = sigmoid(γ_raw) ∈ (0,1)
    π_m = masked_softmax_m( [log(max(r_m,eps)) + γ*c_m] / τ )

其中 π_m 同时用于直接池化：`h_fast = Σ_m π_m h_m`，以及后续图注意力的模态键权重。比起“差异越大越重要”，这里有 r_m 与 r_j 双侧质量折扣，从机制上限制低质量异质噪声凭差异度强行放大。没有可用的 partner 时互补性退化为0；仅有一个模态时权重退化为1。

注意：h_m 的余弦差异不是可辨识的情绪互补因果效应；这是一种可学习的代理量，需要鲁棒性实验验证。

### 3) 单层稀疏关联 + 残差修正

图的节点为所有模态的查询证据 z_{m,q}，节点 i 的源模态为 m(i)。用同一个 π_{m(j)} 调整键侧注意力，并在候选键中选取 Top-K：

    S_ij = cos(W_Q z_i, W_K z_j) * sqrt(d) + log(max(π_{m(j)},eps))
    A_ij = softmax_j(TopK_j(S_ij), available(j))
    v_i = Σ_j A_ij W_V z_j
    z'_i = LN(z_i + sigmoid(G[z_i; W_O v_i]) ⊙ Dropout(W_O v_i))

输出结构表示 `h_rel = Σ_i π_{m(i)} z'_i / Q`，再采用单个直接头和**结构残差修正**：

    y_fast = f(h_fast)
    g = sigmoid( Gate([h_rel - h_fast ; Σ_m π_m r_m]) )
    y_hat = y_fast + g * Delta(h_rel - h_fast)

因此结构路径不能再“独立另起一个完整预测头”，而只能学习直接共识未能解释的修正。移除了独立双头竞争、图传播后额外 Transformer、多重冲突门控。

### 最简学习目标

    L = L_task + λ_u L_uni + λ_q L_quality

* `L_task`：回归为0.7×SmoothL1(beta=0.5)+0.3×MSE；分类为CE。
* `L_uni`：仅对可用模态上的共享预测探针施加监督。
* `L_quality`：可靠性头与 detached 探针质量目标的MSE。
* 默认 λ_u=0.10、λ_q=0.05，需在验证集调参，不应被描述为跨数据集最优常数。
* 不使用重建/正交/反事实/梯度对齐等额外目标。

## III. 相对提供工程的关键精简

| 工程对象 | 上一优化版 | RCSE-Lite |
| --- | --- | --- |
| 解耦 | task / appearance / nuisance + reconstruct | 删除；仅保留直接证据表征 |
| 路由 | 信心 + LOO 影响 + 竞争 | 仅一个可靠性折扣互补路由 |
| 结构推理 | 稀疏图 + 同槽共享 + Transformer | 单层稀疏关联 + 门控残差 |
| 仲裁 | 快/慢双完整头 + 冲突门 | 直接预测 + 结构残差修正 |
| 辅助监督 | uni + calibration + reconstruction + orth + optional gradient alignment | uni + calibration |
| 失效保护 | 掩码、缺失模态和 dropout | 延续并单测；同一路由约束两个交互阶段 |

## IV. 原创性定位应如何陈述

可以主张的候选方法贡献：

1. **耦合的证据授权机制**：统一 π_m 同时约束模态级直接路径、节点级稀疏关联和结构读出，避免同一模态在不同环节分别被独立强化。
2. **可信差异代理量**：用源模态与 peer 双向可靠性折扣调节异质证据的互补价值，适用于缺失模态时的归一化退化。
3. **结构修正而非预测头堆叠**：以直接路径为锚点，关系信息仅作为可控修正，便于做相关机制的分离消融。

不能直接主张：已证明因果认知机制、新的超图算子、Mamba 等价计算、理论保证最优、高精度已经验证、某论文原方案的直接复现。创新性需与 CICA、MSBF、CASDF、GraphMamba 及同类可信门控/稀疏推理文献作全面差异检索，不能把“组合后不同”直接当作已证原创性。

## V. 对照和论文实验必须包含

A. **主结果**：MOSI 与 CH-SIMSv2 的固定特征版本、标准划分、同一评估口径；至少3个独立随机种子，报告均值、标准差；MOSI 的 MAE/Corr/Acc2/Acc7/F1，以及 CH-SIMSv2 的 MAE/Corr/Acc2/3/5/F1。注意各数据集二分类是否将0计入正类需要单独说明。

B. **关键消融（直接支持三个机制）**：`no_reliability`、`no_complementarity`、`dense_graph`、`no_refinement`；再用 `no_temporal` 和 `no_quality_aux` 解释压缩器与辅助探针是否必要；对比源 `legacy`、`enhanced_v1`。

C. **避免简单相关性推断**：定量验证低质量高差异证据下 RCSE-Lite 是否稳定，不仅展示注意力热图。模拟文本/声学/视觉缺失与加噪，报告同样模型与输入设置下性能跌幅；对共同且互相矛盾的可靠信号样本分层分析。

D. **复杂度**：全部与相同 d、Q、原始特征在同硬件 CPU/GPU 上测量 params、实际延迟、训练时长、显存、batch size；不要只报告模型参数量，也不能混用不同硬件数据。稀疏 TopK 的矩阵 attention 仍先计算 N×N 相似度，计算理论量级仍为 O(N²d)，这里的收益主要来自更少的网络层和节点邻域的受限传播，而非严格线性复杂度。

E. **潜在失败模式**：共享探针可能难以同时适配差异模态；余弦不一致不等价于真正互补信息；序列池化可能损失关键时间依赖；可靠性目标来自自己的预测而非外部客观质量。应在论文讨论这些限制，不做不可支持的科学断言。

## VI. 参考路线边界

* CICA：学习“预测质量—置信门控”这一动机；不是原文双阶段预训练的直接实现。
* GraphMamba：借鉴高效局部建模/结构交互动机；没有 Mamba 层。
* MSBF：借鉴动态主次证据调节；不直接复用其特定融合算子。
* CASDF：借鉴模态协同及自适应语义处理思路；不是 CASDF 原结构。
* KGCF-GA：上一版本使用梯度对齐；本版本刻意移除，提升简洁性。没有使用其外部知识图谱。
* CAMS-AMSS：借鉴噪声与证据可靠性关注；不是复制其原文策略。

正式提交论文时，应逐条校验书目、原文机制、可比实验协议及引用位置。
